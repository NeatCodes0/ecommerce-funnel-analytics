# Milestone 3: Macro Funnel Analysis (October 2019)

## 1. Funnel Stage Conversion Rates
- **View -> Cart CVR:** 27.69%
- **Cart -> Purchase CVR:** 12.86%
- **Overall Session CVR:** 3.36%

## 2. Cart Abandonment Loss
- **Total Abandoned Cart Sessions:** 203,891 sessions
- **Cart Abandonment Rate:** 89.40%
- **Total Abandoned Cart Value:** $5,512,701.50

## 3. Core Analytical Insight
Users exhibit heavy "window-shopping" behavior, using the shopping cart as a temporary wishlist/holding bin. Closing the cart abandonment rate by just 200 basis points (from 89.40% down to 87.40%) would recover approximately $120,000+ in monthly gross sales.
